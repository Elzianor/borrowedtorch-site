In development

Kindling Engine

The in-house engine behind Borrowed Torch games. Built in C# on MonoGame, with a WPF editor for building worlds.

Read the docs NuGet packages

What's inside

Entity component system

Games are built from entities and components, with a shared mesh and material registry.

WPF editor

A desktop editor with the MonoGame viewport embedded right in the window.

Camera system

Free and chase controllers, plus spline camera paths with constant-speed travel.

Cloth simulation

A GPU cloth solver for capes, banners and anything else that should move in the wind.

Raytraced shadows In progress

Shadows computed with ray tracing.

GPU grass In progress

Paint grass areas in the editor; blades are generated on the GPU and drawn instanced.

Status

Kindling is in active development alongside our first game. The full engine will be made public in the future; until then, its libraries ship on NuGet one by one and the docs grow as the engine does.
