A delegate nested in <a class="ref" href="/docs/monoinput-glossary/mouse/mouse-manager/">`MouseManager`</a>: the handler type of an event.

Signature: <code>void PositionChanged(Point newPosition)</code>

| Parameter | Type | Description |
| --- | --- | --- |
| `newPosition` | `Point` | Where the pointer is now, in window pixels. |

Handles [`MouseManager.OnPositionChanged`](/docs/monoinput-glossary/mouse/mouse-manager/#onpositionchanged).
