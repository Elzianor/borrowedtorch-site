A delegate nested in <a class="ref" href="/docs/monoinput-glossary/mouse/mouse-manager/">`MouseManager`</a>: the handler type of an event.

Signature: <code>void HorizontalWheelDeltaChanged(int delta)</code>

| Parameter | Type | Description |
| --- | --- | --- |
| `delta` | `int` | How far the horizontal wheel turned since the update before, positive to the right. |

Handles [`MouseManager.OnHorizontalWheelDeltaChanged`](/docs/monoinput-glossary/mouse/mouse-manager/#onhorizontalwheeldeltachanged).
