A delegate nested in <a class="ref" href="/docs/monoinput-glossary/mouse/mouse-manager/">`MouseManager`</a>: the handler type of an event.

Signature: <code>void WheelDeltaChanged(int delta)</code>

| Parameter | Type | Description |
| --- | --- | --- |
| `delta` | `int` | How far the wheel turned since the update before, positive away from you. |

Handles [`MouseManager.OnWheelDeltaChanged`](/docs/monoinput-glossary/mouse/mouse-manager/#onwheeldeltachanged).
