The glossary has a page for everything the MonoInput library provides, in 5 parts:

- [Button states](/docs/monoinput-glossary/states/): the four states, the base class of every mouse and pad button, and the lists that hold the keys and notes being touched. In the sidebar each class opens to its members.
- [Keyboard](/docs/monoinput-glossary/keyboard/): the keyboard manager and the status of a key held. In the sidebar each type opens to its members.
- [Mouse](/docs/monoinput-glossary/mouse/): the mouse manager, the status it keeps, a mouse button, snapshots of the five buttons, the names of the buttons and the handlers of the four mouse events. In the sidebar each class opens to its members.
- [Gamepads](/docs/monoinput-glossary/gamepads/): the gamepad manager, the status of a player slot, a pad button, the names of the fifteen buttons and the handler of the status event. In the sidebar each class opens to its members.
- [MIDI](/docs/monoinput-glossary/midi/): the MIDI manager, a MIDI input device and the status of a note held. In the sidebar each type opens to its members.
