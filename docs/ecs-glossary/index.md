The glossary has a page for everything the ECS library provides, in two parts:

- [World and entities](/docs/ecs-glossary/world/): the world, the callbacks of its queries, the entity handle, and the interfaces that mark entities and systems. In the sidebar each type opens to its members.
- [Components and stores](/docs/ecs-glossary/components/): the interface that marks components, the store behind each component type, its type-erased face, and the declared defaults of components. In the sidebar each type opens to its members.
