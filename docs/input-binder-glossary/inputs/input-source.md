The kinds of device an input can be on.

An enum, in the namespace `BorrowedTorch.InputBinding.Types`. The <a class="ref prop" href="/docs/input-binder-glossary/inputs/base-input/#source">`Source`</a> of an input, and part of its identity: mouse button 0 and pad button 0 are two inputs. The [inputs page](/docs/input-binder-inputs/#inputsource) shows it in context.

## Values

A key. The only source whose buttons can carry a modifier.

<h3 id="mouse"><code>Mouse</code> <a class="ctx" href="/docs/input-binder-inputs/#inputsource" title="Mouse in context on the inputs page" aria-label="Mouse in context on the inputs page">→</a></h3>

A mouse button, wheel or movement.

<h3 id="gamepad"><code>GamePad</code> <a class="ctx" href="/docs/input-binder-inputs/#inputsource" title="GamePad in context on the inputs page" aria-label="GamePad in context on the inputs page">→</a></h3>

A pad button, trigger or stick.

<h3 id="midi"><code>Midi</code> <a class="ctx" href="/docs/input-binder-inputs/#inputsource" title="Midi in context on the inputs page" aria-label="Midi in context on the inputs page">→</a></h3>

A MIDI note, knob or slider.
