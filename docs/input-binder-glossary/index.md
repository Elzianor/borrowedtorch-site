The glossary has a page for everything the input binder library provides, in three parts:

- [The binder](/docs/input-binder-glossary/binder/): the binder, the handle of a registered action, what a bind returns and its results. In the sidebar each class opens to its members.
- [Actions](/docs/input-binder-glossary/actions/): the base of the actions, the button, one-axis and two-axes actions, and the shapes they come in. In the sidebar each class opens to its members.
- [Inputs](/docs/input-binder-glossary/inputs/): the base of the inputs, the button, one-axis and two-axes inputs, the factories, and the sources, states and modifiers of inputs. In the sidebar each class opens to its members.
