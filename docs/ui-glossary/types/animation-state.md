An enum. The [styles page](/docs/ui-styles/#animationstate) shows it in context.

## Values

<h3 id="notstarted"><code>NotStarted</code> <a class="ctx" href="/docs/ui-styles/#animationstate" title="NotStarted in context on the styles page" aria-label="NotStarted in context on the styles page">➤</a></h3>

Created or reset, not started yet.

<h3 id="running"><code>Running</code> <a class="ctx" href="/docs/ui-styles/#animationstate" title="Running in context on the styles page" aria-label="Running in context on the styles page">➤</a></h3>

Advancing with every update.

<h3 id="paused"><code>Paused</code> <a class="ctx" href="/docs/ui-styles/#animationstate" title="Paused in context on the styles page" aria-label="Paused in context on the styles page">➤</a></h3>

Stopped where it was; `Start` continues it.

<h3 id="completed"><code>Completed</code> <a class="ctx" href="/docs/ui-styles/#animationstate" title="Completed in context on the styles page" aria-label="Completed in context on the styles page">➤</a></h3>

All runs are done; `Reset` makes it playable again.
