The cursors of [drag and drop](/docs/ui-images/#drag-and-drop). Disposable like <a class="ref" href="/docs/ui-glossary/types/mouse-cursors-set/">`MouseCursorsSet`</a>.

A class deriving from [`DisposableBase`](/docs/ui-glossary/types/disposable-base/). The [styles page](/docs/ui-styles/#draganddropcursors) shows it in context.

Names are coloured by what they are: a <span class="kb kb-prop">property</span>, a <span class="kb kb-method">method</span> or an <span class="kb kb-event">event</span>; values and fields keep the plain colour.

## Properties

<h3 id="draghovercursor"><span class="prop"><code>DragHoverCursor</code></span> <a class="ctx" href="/docs/ui-styles/#draganddropcursors" title="DragHoverCursor in context on the styles page" aria-label="DragHoverCursor in context on the styles page">→</a></h3>

`MouseCursor` · Shown instead of `HoverCursor` over an element that can be dragged.

<h3 id="dragpressedcursor"><span class="prop"><code>DragPressedCursor</code></span> <a class="ctx" href="/docs/ui-styles/#draganddropcursors" title="DragPressedCursor in context on the styles page" aria-label="DragPressedCursor in context on the styles page">→</a></h3>

`MouseCursor` · Shown instead of `PressedCursor` while the left button is held on an element that can be dragged.

<h3 id="dropallowedcursor"><span class="prop"><code>DropAllowedCursor</code></span> <a class="ctx" href="/docs/ui-styles/#draganddropcursors" title="DropAllowedCursor in context on the styles page" aria-label="DropAllowedCursor in context on the styles page">→</a></h3>

`MouseCursor` · Shown over a drop target that accepts what is dragged.

<h3 id="dropdeniedcursor"><span class="prop"><code>DropDeniedCursor</code></span> <a class="ctx" href="/docs/ui-styles/#draganddropcursors" title="DropDeniedCursor in context on the styles page" aria-label="DropDeniedCursor in context on the styles page">→</a></h3>

`MouseCursor` · Shown over a drop target that refuses what is dragged.
