A delegate: the handler type of an event.

Signature: <code>void TextChanged(<a href="/docs/ui-glossary/elements/base-element/">BaseElement</a> sender, string text)</code>

| Parameter | Type | Description |
| --- | --- | --- |
| `sender` | <a class="ref" href="/docs/ui-glossary/elements/base-element/">`BaseElement`</a> | The element that raised the event. |
| `text` | `string` | The new text. |

Handles [`RichTextBox.OnTextChanged`](/docs/ui-glossary/elements/rich-text-box/#ontextchanged).
