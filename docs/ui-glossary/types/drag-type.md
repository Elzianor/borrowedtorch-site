An enum. The [base element page](/docs/ui-base-element/#dragtype) shows it in context.

## Values

<h3 id="none"><code>None</code> <a class="ctx" href="/docs/ui-base-element/#dragtype" title="None in context on the base element page" aria-label="None in context on the base element page">➤</a></h3>

<h3 id="dragonly"><code>DragOnly</code> <a class="ctx" href="/docs/ui-base-element/#dragtype" title="DragOnly in context on the base element page" aria-label="DragOnly in context on the base element page">➤</a></h3>

<h3 id="draganddrop"><code>DragAndDrop</code> <a class="ctx" href="/docs/ui-base-element/#dragtype" title="DragAndDrop in context on the base element page" aria-label="DragAndDrop in context on the base element page">➤</a></h3>
