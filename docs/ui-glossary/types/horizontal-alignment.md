An enum. The [base element page](/docs/ui-base-element/#horizontalalignment) shows it in context.

## Values

<h3 id="stretch"><code>Stretch</code> <a class="ctx" href="/docs/ui-base-element/#horizontalalignment" title="Stretch in context on the base element page" aria-label="Stretch in context on the base element page">🠆</a></h3>

Fills the slot less both margins when the element has no <a class="ref dp" href="/docs/ui-glossary/elements/base-element/#desiredwidth">`DesiredWidth`</a>, otherwise sits at the left margin.

<h3 id="left"><code>Left</code> <a class="ctx" href="/docs/ui-base-element/#horizontalalignment" title="Left in context on the base element page" aria-label="Left in context on the base element page">🠆</a></h3>

At the left margin.

<h3 id="center"><code>Center</code> <a class="ctx" href="/docs/ui-base-element/#horizontalalignment" title="Center in context on the base element page" aria-label="Center in context on the base element page">🠆</a></h3>

Centred between the left and the right margin.

<h3 id="right"><code>Right</code> <a class="ctx" href="/docs/ui-base-element/#horizontalalignment" title="Right in context on the base element page" aria-label="Right in context on the base element page">🠆</a></h3>

At the right margin.
