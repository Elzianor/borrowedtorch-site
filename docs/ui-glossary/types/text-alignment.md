Also used by <a class="ref" href="/docs/ui-glossary/elements/rich-text-box/">`RichTextBox`</a>.

An enum. The [text page](/docs/ui-text/#textalignment) shows it in context.

## Values

<h3 id="left"><code>Left</code> <a class="ctx" href="/docs/ui-text/#textalignment" title="Left in context on the text page" aria-label="Left in context on the text page">➤</a></h3>

Lines start at the left margin.

<h3 id="center"><code>Center</code> <a class="ctx" href="/docs/ui-text/#textalignment" title="Center in context on the text page" aria-label="Center in context on the text page">➤</a></h3>

Lines are centred in the width.

<h3 id="right"><code>Right</code> <a class="ctx" href="/docs/ui-text/#textalignment" title="Right in context on the text page" aria-label="Right in context on the text page">➤</a></h3>

Lines end at the right margin.

<h3 id="justify"><code>Justify</code> <a class="ctx" href="/docs/ui-text/#textalignment" title="Justify in context on the text page" aria-label="Justify in context on the text page">➤</a></h3>

In a wrapping <a class="ref" href="/docs/ui-glossary/elements/rich-text-box/">`RichTextBox`</a>, the spaces of each line are widened so the line fills the width (not the last line of a paragraph). A label draws it like <a class="ref" href="/docs/ui-glossary/types/text-alignment/#left">`Left`</a>.
