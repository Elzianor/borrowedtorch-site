An enum. The [controls page](/docs/ui-controls/#slidertype) shows it in context.

## Values

<h3 id="slider"><code>Slider</code> <a class="ctx" href="/docs/ui-controls/#slidertype" title="Slider in context on the controls page" aria-label="Slider in context on the controls page">➤</a></h3>

No end parts: the thumb moves along the whole length.

<h3 id="sliderwithcaps"><code>SliderWithCaps</code> <a class="ctx" href="/docs/ui-controls/#slidertype" title="SliderWithCaps in context on the controls page" aria-label="SliderWithCaps in context on the controls page">➤</a></h3>

Caps half the slider's thickness long at both ends; clicking one jumps to <span class="dp">`Min`</span> or <span class="dp">`Max`</span>.

<h3 id="scrollbar"><code>ScrollBar</code> <a class="ctx" href="/docs/ui-controls/#slidertype" title="ScrollBar in context on the controls page" aria-label="ScrollBar in context on the controls page">➤</a></h3>

Square buttons at both ends that make a plain step; track clicks page when <a class="ref prop" href="/docs/ui-glossary/elements/slider/#contentsize">`ContentSize`</a> and <a class="ref prop" href="/docs/ui-glossary/elements/slider/#viewsize">`ViewSize`</a> are set.

<h3 id="scrollbarnobuttons"><code>ScrollBarNoButtons</code> <a class="ctx" href="/docs/ui-controls/#slidertype" title="ScrollBarNoButtons in context on the controls page" aria-label="ScrollBarNoButtons in context on the controls page">➤</a></h3>

A scroll bar without the end buttons.
