An enum. The [lists and menus page](/docs/ui-lists/#contextmenusubmenusopentype) shows it in context.

## Values

<h3 id="onhover"><code>OnHover</code> <a class="ctx" href="/docs/ui-lists/#contextmenusubmenusopentype" title="OnHover in context on the lists and menus page" aria-label="OnHover in context on the lists and menus page">🠆</a></h3>

A sub-menu opens when the mouse is over its item, and closes when the mouse is over neither the item, the sub-menu nor a sub-menu opened from it.

<h3 id="onclick"><code>OnClick</code> <a class="ctx" href="/docs/ui-lists/#contextmenusubmenusopentype" title="OnClick in context on the lists and menus page" aria-label="OnClick in context on the lists and menus page">🠆</a></h3>

A click on the item opens or closes its sub-menu; a press on the menu outside of its items (its border, a separator) closes the sub-menus opened from it.
