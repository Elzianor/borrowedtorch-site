An enum. The [lists and menus page](/docs/ui-lists/#listboxselectionmode) shows it in context.

## Values

<h3 id="single"><code>Single</code> <a class="ctx" href="/docs/ui-lists/#listboxselectionmode" title="Single in context on the lists and menus page" aria-label="Single in context on the lists and menus page">➤</a></h3>

One row at most is selected.

<h3 id="multiple"><code>Multiple</code> <a class="ctx" href="/docs/ui-lists/#listboxselectionmode" title="Multiple in context on the lists and menus page" aria-label="Multiple in context on the lists and menus page">➤</a></h3>

Several rows can be selected, with Ctrl and Shift clicks or from code.
