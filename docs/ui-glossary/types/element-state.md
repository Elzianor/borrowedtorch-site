From the lowest to the highest.

An enum. The [base element page](/docs/ui-base-element/#elementstate) shows it in context.

## Values

<h3 id="normal"><code>Normal</code> <a class="ctx" href="/docs/ui-base-element/#elementstate" title="Normal in context on the base element page" aria-label="Normal in context on the base element page">🠆</a></h3>

Nothing is happening to the element.

<h3 id="hover"><code>Hover</code> <a class="ctx" href="/docs/ui-base-element/#elementstate" title="Hover in context on the base element page" aria-label="Hover in context on the base element page">🠆</a></h3>

The element takes the mouse.

<h3 id="mousebuttonsactivity"><code>MouseButtonsActivity</code> <a class="ctx" href="/docs/ui-base-element/#elementstate" title="MouseButtonsActivity in context on the base element page" aria-label="MouseButtonsActivity in context on the base element page">🠆</a></h3>

A mouse button pressed on the element is held.

<h3 id="dropdenied"><code>DropDenied</code> <a class="ctx" href="/docs/ui-base-element/#elementstate" title="DropDenied in context on the base element page" aria-label="DropDenied in context on the base element page">🠆</a></h3>

A dragged element is over the element and it does not take the drop.

<h3 id="dropallowed"><code>DropAllowed</code> <a class="ctx" href="/docs/ui-base-element/#elementstate" title="DropAllowed in context on the base element page" aria-label="DropAllowed in context on the base element page">🠆</a></h3>

A dragged element is over the element and it takes the drop.
