An enum. The [text page](/docs/ui-text/#richtextboxtype) shows it in context.

## Values

<h3 id="readonly"><code>ReadOnly</code> <a class="ctx" href="/docs/ui-text/#richtextboxtype" title="ReadOnly in context on the text page" aria-label="ReadOnly in context on the text page">➤</a></h3>

The text is shown, scrolled and copied, not edited. Links and rich formatting work.

<h3 id="readwrite"><code>ReadWrite</code> <a class="ctx" href="/docs/ui-text/#richtextboxtype" title="ReadWrite in context on the text page" aria-label="ReadWrite in context on the text page">➤</a></h3>

The text can be edited with the mouse and the keyboard. Tags are shown as typed.
