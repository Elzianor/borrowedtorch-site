An enum. The [images page](/docs/ui-images/#imagefill) shows it in context.

## Values

<h3 id="stretch"><code>Stretch</code> <a class="ctx" href="/docs/ui-images/#imagefill" title="Stretch in context on the images page" aria-label="Stretch in context on the images page">🠆</a></h3>

The whole texture is stretched over the image. The default.

<h3 id="center"><code>Center</code> <a class="ctx" href="/docs/ui-images/#imagefill" title="Center in context on the images page" aria-label="Center in context on the images page">🠆</a></h3>

The texture at its own size in the middle of the image. A texture larger than the image is cut at its edges.

<h3 id="tile"><code>Tile</code> <a class="ctx" href="/docs/ui-images/#imagefill" title="Tile in context on the images page" aria-label="Tile in context on the images page">🠆</a></h3>

The texture is repeated from the top left corner in both directions. The last tiles are cut at the right and bottom edges, not squeezed.

<h3 id="tilex"><code>TileX</code> <a class="ctx" href="/docs/ui-images/#imagefill" title="TileX in context on the images page" aria-label="TileX in context on the images page">🠆</a></h3>

Repeated along the width, stretched over the height.

<h3 id="tiley"><code>TileY</code> <a class="ctx" href="/docs/ui-images/#imagefill" title="TileY in context on the images page" aria-label="TileY in context on the images page">🠆</a></h3>

Repeated along the height, stretched over the width.
