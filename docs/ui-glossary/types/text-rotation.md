An enum. The [text page](/docs/ui-text/#textrotation) shows it in context.

## Values

<h3 id="none"><code>None</code> <a class="ctx" href="/docs/ui-text/#textrotation" title="None in context on the text page" aria-label="None in context on the text page">➤</a></h3>

The text is drawn as usual.

<h3 id="clockwise"><code>Clockwise</code> <a class="ctx" href="/docs/ui-text/#textrotation" title="Clockwise in context on the text page" aria-label="Clockwise in context on the text page">➤</a></h3>

A quarter turn to the right: the text reads from the top down.

<h3 id="counterclockwise"><code>CounterClockwise</code> <a class="ctx" href="/docs/ui-text/#textrotation" title="CounterClockwise in context on the text page" aria-label="CounterClockwise in context on the text page">➤</a></h3>

A quarter turn to the left: the text reads from the bottom up.

<h3 id="upsidedown"><code>UpsideDown</code> <a class="ctx" href="/docs/ui-text/#textrotation" title="UpsideDown in context on the text page" aria-label="UpsideDown in context on the text page">➤</a></h3>

A half turn.
