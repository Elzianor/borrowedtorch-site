An enum. The [layout page](/docs/ui-layout/#scrollbars) shows it in context.

## Values

<h3 id="none"><code>None</code> <a class="ctx" href="/docs/ui-layout/#scrollbars" title="None in context on the layout page" aria-label="None in context on the layout page">🠆</a></h3>

No scroll bars and no wheel scrolling; scrolling from code still works.

<h3 id="vertical"><code>Vertical</code> <a class="ctx" href="/docs/ui-layout/#scrollbars" title="Vertical in context on the layout page" aria-label="Vertical in context on the layout page">🠆</a></h3>

A vertical bar at the right while the content is taller than the view.

<h3 id="horizontal"><code>Horizontal</code> <a class="ctx" href="/docs/ui-layout/#scrollbars" title="Horizontal in context on the layout page" aria-label="Horizontal in context on the layout page">🠆</a></h3>

A horizontal bar at the bottom while the content is wider than the view.

<h3 id="both"><code>Both</code> <a class="ctx" href="/docs/ui-layout/#scrollbars" title="Both in context on the layout page" aria-label="Both in context on the layout page">🠆</a></h3>

Each bar while it is needed.
