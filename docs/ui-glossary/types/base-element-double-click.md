A delegate: the handler type of an event.

Signature: <code>void DoubleClick(<a href="/docs/ui-glossary/elements/base-element/">BaseElement</a> sender, <a href="/docs/ui-glossary/types/mouse-click-event-args/">MouseClickEventArgs</a> e)</code>

| Parameter | Type | Description |
| --- | --- | --- |
| `sender` | <a class="ref" href="/docs/ui-glossary/elements/base-element/">`BaseElement`</a> | The element that raised the event. |
| `e` | <a class="ref" href="/docs/ui-glossary/types/mouse-click-event-args/">`MouseClickEventArgs`</a> | Where the mouse was and the states of its buttons. |

Handles [`BaseElement.OnDoubleClick`](/docs/ui-glossary/elements/base-element/#ondoubleclick).
