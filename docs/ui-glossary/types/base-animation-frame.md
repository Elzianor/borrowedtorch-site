The abstract base of the frames an `Animation<T>` takes. It has no public members; use `SmoothAnimationFrame<T>` or `DiscreteAnimationFrame<T>`.

An abstract class. The [styles page](/docs/ui-styles/#baseanimationframet) shows it in context.
