An empty element to draw a dividing line or leave a gap: give it a size along one side, stretch it along the other, and it fills itself with its `BackgroundColor`.

`Separator` derives from [`ContentContainer`](/docs/ui-glossary/content-container/) and has its members too. The [layout page](/docs/ui-layout/#separator) shows it in context, with code and screenshots.

Badges tell what each name is: <span class="kb kb-prop">P</span> a plain property, <span class="kb kb-method">M</span> a method, <span class="kb kb-event">E</span> an event, and <span class="kb kb-dp">DP</span> a dependency property, which a style, a binding or an animation can set.
