How a display is turned, as Settings has it (System, Display, Display orientation).

An enum, in the namespace `BorrowedTorch.Capabilities`. A display's size and current mode are given as turned: a 1920 × 1080 monitor stood on its side is 1080 wide. <a class="ref prop" href="/docs/capabilities-glossary/displays/display/#orientation">`Display.Orientation`</a> gives it. The [displays page](/docs/capabilities-displays/#how-a-display-is-set) shows it in context.
