Each type has a page listing its members in alphabetical order, each with its type or signature and what it does, and each enum its values. The sidebar lists the members of each type under its name.

| Type | What it is |
| --- | --- |
| [`Displays`](/docs/capabilities-glossary/displays/displays/) | The displays on the desktop. |
| [`Display`](/docs/capabilities-glossary/displays/display/) | A display on the desktop: which one it is, where it is, how it is set and every mode it can be set to. |
| [`DisplayMode`](/docs/capabilities-glossary/displays/display-mode/) | A mode a display can be set to: its size in pixels, its refresh rate in whole hertz and its color depth. |
| [`Resolution`](/docs/capabilities-glossary/displays/resolution/) | A display's size in pixels, for a game's resolution setting. |
| [`PixelRectangle`](/docs/capabilities-glossary/displays/pixel-rectangle/) | A rectangle of the desktop, in the displays' own pixels. |
| [`DisplayOrientation`](/docs/capabilities-glossary/displays/display-orientation/) | How a display is turned, as Settings has it (System, Display, Display orientation). |
