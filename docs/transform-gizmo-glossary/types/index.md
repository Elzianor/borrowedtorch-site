Every enum of the transform gizmo library has a page with its values.

## Enums

| Type | What it is |
| --- | --- |
| [`GizmoAxis`](/docs/transform-gizmo-glossary/types/gizmo-axis/) | A handle by its axis: X, Y, Z, the pivot, or none. |
| [`GizmoCapabilities`](/docs/transform-gizmo-glossary/types/gizmo-capabilities/) | Flags: the modes and frames a target offers. |
| [`GizmoMode`](/docs/transform-gizmo-glossary/types/gizmo-mode/) | Which handles the gizmo shows: move, rotate or scale. |
| [`GizmoSpace`](/docs/transform-gizmo-glossary/types/gizmo-space/) | The frame of move and rotate: the world's axes or the target's own. |
