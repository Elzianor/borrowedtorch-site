Each type has a page listing its members in alphabetical order, each with its type or signature and what it does. The sidebar lists the members of each type under its name.

| Type | What it is |
| --- | --- |
| [`FractalNoise`](/docs/randomness-glossary/noise/fractal-noise/) | Several octaves of gradient noise, each finer and fainter, summed to a value from −1 to 1. |
| [`FractalSettings`](/docs/randomness-glossary/noise/fractal-settings/) | The frequency, octaves, lacunarity and gain of a fractal noise, as a record of plain data. |
| [`GradientNoise`](/docs/randomness-glossary/noise/gradient-noise/) | One layer of Perlin-style gradient noise from −1 to 1, with no state and no period. |
