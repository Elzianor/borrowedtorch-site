Each type has a page listing its members in alphabetical order, each with its type or signature and what it does. The sidebar lists the members of each type under its name.

| Type | What it is |
| --- | --- |
| [`Rng`](/docs/randomness-glossary/streams/rng/) | A seeded PCG32 generator: integers, doubles, chances, picks, shuffles and forks. |
| [`StableHash`](/docs/randomness-glossary/streams/stable-hash/) | Hashes that are the same on every run, platform and .NET version: for strings, pairs of numbers and single numbers. |
